# Communication examples

Read when a message needs help with tone, unfamiliar terms, or a complex handoff. These are examples, not instructions to reuse old names, dates, or destinations. Use actual task facts.

## Plain-language alternatives

Choose a replacement only when it preserves the meaning. Otherwise explain the correct term.


Use these clearer alternatives when they fit the situation:

| Avoid | Use instead |
|---|---|
| blocker | problem or what is stopping the work |
| the blocker is explicit | the problem is now clear |
| explicit | clear or clearly stated |
| parent | main task or main assignment |
| parent task | main task or main assignment |
| parent has been reopened | the main task has been opened again |
| subtask | a smaller task within the main task; explain once when needed |
| canonical | approved, correct, or official |
| canonical route map | approved list of pages and links |
| canonical link | official link we will use |
| route map | approved list of pages and links |
| routes | separate pages or customer paths |
| endpoint | explain its actual role; an API address is not necessarily a web page |
| CTA | button or link |
| evidence | proof, followed by the exact proof required |
| error evidence | screenshot or copy of the error |
| evidence pack | proof pack containing screenshots, links, and files |
| independent work | work you can do while you wait |
| deduplication | removing duplicates |
| root domain | main website address |
| subdomain | extra web address, such as offers.example.com |
| GHL | GoHighLevel, the website and funnel tool |
| DNS record | a setting that connects a web address to a website or tool |
| fake-contact path | fake person or fake contact process |
| reviewable | ready for Jack or the assigned reviewer to check |
| completion report is reviewable | the finish report is ready for review |
| parent complete | main task done |
| do not mark the parent complete | do not mark the main task done |
| commercial-use licence | written permission to use the item for business |
| foundry | company or person that created the font |



## Message to Mark

```text
@Mark Tagapulot

We now know why the GoHighLevel funnel cannot use the main website address. That address is already connected to the AI Studio website.

Please finish the new web-address plan today:

- Recommend one extra web address for the funnel, such as offers.example.com.
- Explain briefly why you recommend it.
- List the exact DNS settings needed to connect it.
- List the steps for connecting it inside GoHighLevel.
- Name the four pages that will use the new address.
- Attach a screenshot or copy of the error showing why the main website address cannot be used.

Jack needs your recommendation before he can decide. John must wait for Jack’s decision before reconnecting the Guide and Plan Your Trip buttons.

Do not mark the main task done until John has the approved list of pages and links and the finish report is ready for review.
```

## Message to Paul

```text
@Paul Pilapil

Thank you for updating the logo files and the shared Drive folder.

The main branding task is open again because we still need proof that we can legally use both fonts for business.

Please finish the font check by September 3:

- Find the licence for Torus Pro Regular.
- Find the licence for Motherline Sans Regular.
- Record where each font came from.
- Name the person or company that created each font.
- Record the font version.
- Confirm whether each licence allows use in logos, websites, social media, printed materials, PDFs, and editable Canva templates.

A free download page is not enough. We need the actual licence terms or a clear statement from the font owner.

Please upload the licence proof to the shared Drive brand folder and paste the folder link in this task.

If either font requires payment or the rights are unclear, stop and give Jack the available options and costs. Do not buy or share the font.

Mark the main branding task done only after the licence proof has been reviewed.
```
